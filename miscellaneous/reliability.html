Reliability

See slides.

R

You need to learn about the following R functions:

R Description
alpha() Cronbach’s alpha

The function alpha() is part of the psych package.

Examples:

Cronbach’s alpha coefficient for unstandardized items item1-item10:

psych::alpha(
  data |> select(item1:item10)
)

Standardized items, sign of each item as is:

psych::alpha(
  data |> select(item1:item10),
  check.keys = FALSE
)

Store a scale as a new variable:

data <- data |>
  mutate(
    SR = rowMeans(
      select(., item1:item10),
      na.rm = TRUE
    )
  )

Display item statistics and alpha if item deleted:

psych::alpha(
  data |> select(item1:item10)
)

The output includes Cronbach’s alpha, item-total correlations, and the value of alpha if each item is deleted in turn.

Assignments

  1. Use the dataset sbs399_sexroles. We assess the reliability for the sex role items in this dataset.

  • Check the descriptives of the sex role items sexrol1-sexrol5, including the number of missing values for each of the variables.

  • Do a reliability analysis of the standardized items, keeping the items directed as in the data. What is the value (estimate) of Cronbach’s alpha?

  • Check the alpha’s if each item is deleted from the scale in turn. The deletion of which item will increase the reliability? Why?

Hint: Verify that it is negatively correlated to the other items and should be recoded first.

  • Reverse item 5 and redo the analysis. What is the value of Cronbach’s alpha now?

  • Check the alpha’s if items are deleted. The deletion of which item will increase the reliability? Is this increase large? Discuss the advantage and drawback of deleting this item. For instance, one drawback of deleting an item is the decrease in the range of attitude measures.

  • What is the sample size in the data and what is the sample size in the analysis?

  • Replace the missing values for a variable with the mean of this variable. Do again a reliability analysis. Notice that the reliability goes down. Why will this be the case? What would be a better imputation for the missing values?

  1. Use the dataset muslimrights. We now assess the reliability for scales in this dataset. Refer to your results in the section on factor analysis. We want to assess the reliability of the two factors of the two-dimensional solution and the reliability of the unidimensional solution.

  • Do again the factor analysis with an oblique rotation. Notice that two items are difficult to place: items 2 and 7.

  • Assess reliability separately for items 1 to 4 and for items 5 to 7. What happens to the reliability if you delete items 2 and 7?

  • Do a reliability analysis for items 1 to 7 together. What happens if you delete items 2 and 7?

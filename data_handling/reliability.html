R

You need to learn about the following R functions:

R Description
alpha() Cronbach’s alpha

The function alpha() is part of the psych package. Note that there is also a function alpha(), with a completely different purpose, in the package ggplot2 (which is also loaded when we load tidyverse). So be aware that R will use whatever you loaded last. To avoid ambiguity, you might want to explicitly refer to the package when calling the function: psych::alpha().

Examples:

Cronbach’s alpha coefficient for variables item1to item10:

library(psych)
library(dplyr)

alpha_results <- data |> 
                  select(item1:item10) |> 
                  alpha()

If you print the object alpha_results you will see lots of results. The most important are:

  • raw_alpha: Cronbach’s alpha for items as they are
  • std.alpha: Cronbach’s alpha for standardized items
  • The panel Reliability if an item is dropped shows, as the name suggets, the results we would obatin if we dropped each item.
  • Panel Item statistics:
    • raw.r: correlation of the item with the total scale
    • std.r: same as above, if items were all standardized
    • r.drop: correlation of the item with a scale formed by all the other items

If we set the argument check.keys to TRUE in alpha(), the function will try to detect and automatically reverse items that seem to be in the opposite direction of the rest of the scale (for example, an item capturing negative attitudes when all other items capture positive attitudes):

data |> 
  select(item1:item10) |> 
  alpha(check.keys = TRUE)

After we check the reliability and decide which items to include (and with which coding), we probably want to create a scale by taking the average of items. alpha() does this automatically, and you can get the computed scale with alpha_results$scores. But make sure you understand which variables (and with coding) were used for this computation. For example, if you decide to drop an item, you have to use the results from a call to alpha() using only the remnaining items. When in doubt, it is better to compute the scale by yourself.

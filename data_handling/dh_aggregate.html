Aggregating data

In this chapter you learn about the two related tasks:

  • Create a new dataset with summary statistics such as group means.
  • Add to a dataset new variables with aggregate statistics such as group means.

To illustrate, consider the following pet dataset with 5 pupils with respondent identifier id, from 2 school classes identified by the variable class, recording the father’s education of the pupil in the variable fedu.

id class fedu
1 1 3
2 1 4
21 2 2
22 2 3
23 2 3

The dataset with class-level summary statistics should contain 2 cases, one for each class, with the mean of fedu in the respective classes, new variable mn_fedu, and the number of observations, new variable n, in each class.

class n mn_fedu
1 2 3.5
2 3 2.6667

The original individual-level dataset enriched with class-level summary statistics should read:

id class fedu mn_fedu n
1 1 3 3.5 2
2 1 4 3.5 2
21 2 2 2.6667 3
22 2 3 2.6667 3
23 2 3 2.6667 3

Thus, the variable mn_fedu records contextual, class-level, information in de-aggregated form: the mean education of the parents in a pupil’s class is treated as an individual attribute.

R

In this part you need to study the following R functions:

Function Description
summarise() Create a dataset with summary statistics
mutate() Add new variables to the existing dataset
.by Apply summarise() or mutate() within groups
n() Count the number of observations in a group
mean() Compute group means
min() Compute group minimums
max() Compute group maximums

We present a short code fragment to accomplish the data manipulation described in the preamble.

Add the mean of fedu by class as a variable, N = 5:

data <- data |>
  mutate(
    mn_fedu = mean(fedu, na.rm = TRUE),
    .by = class
  )

Add variable nclass: number of observations in each class:

data <- data |>
  mutate(
    nclass = n(),
    .by = class
  )

Create a N = 2 contextual dataset with the N and mean of fedu, grouped by class:

class_data <- data |>
  summarise(
    n = n(),
    mn_fedu = mean(fedu, na.rm = TRUE),
    .by = class
  )

1. People nested within neighborhoods within cities

We consider a simple synthetic dataset ex_aggr.dta of people nested within neighborhoods nested within cities.

city city code

neighb neighborhood code

employ employment status, 1 = employed, 0 = unemployed

ethnic 1 = native Dutch; 2 = western immigrant; 3 = nonwestern immigrant

  • Create a separate dataset recording the fractions of unemployed and the ethnic composition of cities, i.e., the fractions of native Dutch, western immigrants, and nonwestern immigrants.
  • Add variables to the original dataset with the fractions, or percentages, of unemployed and the ethnic composition of the neighborhood, i.e., the fractions, or percentages, of Dutch, western, and nonwestern people in the neighborhood. Briefly consider how to also add the information aggregated at the city level.
  • Add a variable representing the fraction, or percentage, of ethnic ingroup in the neighborhood.

2. Education within couples

Use hin95_ext.dta. The dataset contains data on couples, married or cohabiting, indicated by the household identifier hrespnr.

  • Add a variable for the mean education of the household. Thus, this variable should have the same value for both partners.
  • Add a variable for the minimum education of the household. Add a variable for the maximum education of the household.
  • Add a variable recording the absolute difference of the levels of education of husband and wife.

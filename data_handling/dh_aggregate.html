Aggregating data

In this chapter you learn about the two related tasks:

  • Create a new dataset with summary statistics such as group means.
  • Add to a dataset new variables with aggregate statistics such as group means.

To illustrate, consider the following toy dataset with 5 pupils with respondent identifier id, from 2 school classes identified by the variable class, recording the father’s education of the pupil in the variable fedu.

id class fedu
1 1 3
2 1 4
21 2 2
22 2 3
23 2 3

The dataset with class-level summary statistics should contain 2 cases, one for each class, with the mean of fedu in the respective classes, new variable mean_fedu, and the number of observations, new variable n, in each class.

class n mean_fedu
1 2 3.5
2 3 2.6667

The original individual-level dataset enriched with class-level summary statistics should read:

id class fedu mean_fedu n
1 1 3 3.5 2
2 1 4 3.5 2
21 2 2 2.6667 3
22 2 3 2.6667 3
23 2 3 2.6667 3

Thus, the variable mean_fedu records contextual, class-level, information; the mean education of the parents in a pupil’s class is treated as an individual attribute.

R

In this part you need to study the following R functions:

Function Description
summarise() Create a dataset with summary statistics
mutate() Add new variables to the existing dataset
.by Apply summarise() or mutate() within groups
n() Count the number of observations in a group

We present a short code fragment to accomplish the data manipulation described in the preamble.

Add the mean of fedu by class as a variable:

data <- data |>
  mutate(
    mean_fedu = mean(fedu, na.rm = TRUE),
    .by = class
  )

Note that we could also have used the function group_by() to create a grouping structure, and then mutate() would have been applied within the groups. The .by argument is a convenient (and more recent) alternative that applies the operation separately within groups without permanently changing the grouping structure of the dataset. So the code below is a valid alternative to the code above:

data <- data |> 
  group_by(class) |>
  mutate(
    mean_fedu = mean(fedu, na.rm = TRUE)
  ) |>
  ungroup()

(Read more about group_by() and .by here.)

Add variable nclass: number of observations in each class:

data <- data |>
  mutate(
    nclass = n(),
    .by = class
  )

Create a N = 2 contextual dataset with the N and mean of fedu, grouped by class:

class_data <- data |>
  summarise(
    n = n(),
    mean_fedu = mean(fedu, na.rm = TRUE),
    .by = class
  )

Make sure you understand the difference between mutate() and summarise(). The former enriches the individual-level dataset with class-level summary statistics, while the latter reduces the dataset to one row per group, thus creating a new dataset with class-level summary statistics.

Assignments

1. People nested within neighborhoods within cities

We consider a simple synthetic dataset ex_aggr.dta of people nested within neighborhoods nested within cities.

  • city city code
  • neighb neighborhood code
  • employ employment status, 1 = employed, 0 = unemployed
  • ethnic 1 = native Dutch; 2 = western immigrant; 3 = nonwestern immigrant
  1. Create a separate dataset recording, for each city, the number of people, the fraction of unemployed and the ethnic composition, i.e., the frac8tions of native Dutch, western immigrants, and nonwestern immigrants.
  2. Add variables to the original dataset with the percentages of unemployed and the ethnic composition of the neighborhood, i.e., the fractions, or percentages, of Dutch, western, and nonwestern people in the neighborhood. Consider how to also add the information aggregated at the city level.
  3. Add a variable representing the percentage of ethnic ingroup in the neighborhood.
  4. What is the average percentage of ethnic ingroup in the neighborhood for native Dutch, western immigrants, and nonwestern immigrants?

2. Education within couples

Use hin95_ext.dta. The dataset contains data on couples (married or cohabiting), as well as people living alone. The households are indicated by the identifier hrespnr. Keep only the couples, i.e., households with exactly two members. The variable educ records the level of education of the respondent.

  1. Add a variable for the mean education of the household. Thus, this variable should have the same value for both partners.
  2. Add a variable for the minimum education of the household. Add a variable for the maximum education of the household.
  3. Add a variable recording the absolute difference of the levels of education of husband and wife.

Add the percentage of the respondent’s own ethnic group in the neighborhood.

ex_aggr <- ex_aggr |>
  mutate(
    pc_ingroup = recode_values(ethnic,
                                1 ~ pc_dutch_neighb,
                                2 ~ pc_western_neighb,
                                3 ~ pc_nonwestern_neighb

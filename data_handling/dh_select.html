Selecting cases

In this part you will learn about selecting cases (observations).

Function Description
filter() Select observations satisfying a condition
slice() Select observations by row number
slice_head() Select the first observations
slice_tail() Select the last observations
group_by() Define groups for subsequent operations
.by Apply an operation separately within groups

R

Examples:

Select observations using logical conditions:

data |>   
  filter(sex == 1)
# select observations for which sex equals 1

data |>   
  filter(sex == 1, edu > 3)
# select observations for which sex equals 1 AND edu is larger than 3

data |>   
  filter(sex == 1 | edu >= 3)
# select observations for which sex equals 1 OR edu is at least 3
# the vertical bar means OR, so respondents satisfying either condition are counted


data |> 
  filter(edu != 3)
# select observations in which edu is different than 3


data |> 
  filter((sex == 1 & edu > 3) | (sex == 0 & edu < 3))
# select observations in which one of this is true:
# 1. sex equals 1 and edu is larger than 3
# OR
# 2. sex equals 0 and education is lower than 3

data |> 
  filter(age == max(age))
# select observation(s) whose age equals the maximum age in the dataset, i.e. the 
# oldest person(s). Should use na.rm=TRUE is there are missing values in age

Select observations based on row number:

data |> 
   slice(5) 
# select 5th row

data |>   
  slice(1:20) 
# select rows 1 to 20

data |>   
  slice_head(20)
# select first 20 observations (same as above)

data |>   
  slice_tail(20)
# select the last 20 observations

The same can also be done with filter() and row_number():

data |>   
  filter(row_number() == 5) 
# select 5th row 

data |>   
  filter(row_number() <= 20)  
# select the first 20 observations

data |>   
  filter(row_number() > (n() - 20))
# select the last 20 observations 
# n() gives the total number of rows

Keep a subset of observations:

data_male <- data |>   
  filter(male == 1)  
# create a new dataset containing only observations for which male==1

data_first100 <- data |>   
  slice(1:100)
# create a new dataset containing only the first 100 observations

The argument .by is to apply a filter within groups. This is useful when you want to compare an observation with other observations in each group, and filter based on that. You will learn more about grouped operations in Aggregating data. Suppose each observation belongs to a household, indicated by the id variable hh_id:

data |>   
  filter(row_number() == 1, .by = hh_id)  
# select the first row from *each household*. It is as if we create one dataset per 
# household, selected the first row from each of them, them put them together again

data |>   
  filter(age == max(age), .by = hh_id)  
# select observations where age equals the maximum age *within each household*, i.e. 
# the oldest in each household. Note that this can be more than one person per household
# if they have the same age.

1. Counting observations with filter() and nrow()

Age at most 30.

sbs399 |>
  filter(age <= 30) |>
  nrow()
[1] 1090
# number of respondents aged 30 or younger

Age at least 20.

sbs399 |>
  filter(age >= 20) |>
  nrow()
[1] 3345
# number of respondents aged 20 or older

Age between 20 and 30, boundaries included.

sbs399 |>
  filter(age >= 20, age <= 30) |>
  nrow()
[1] 1085
# between(age, 20, 30) would give the same result

Age between 20 and 30, boundaries excluded.

sbs399 |>
  filter(age > 20, age < 30) |>
  nrow()
[1] 731
# respondents of exactly 20 or exactly 30 are now excluded

Males over 25.

sbs399 |>
  filter(sex == 0, age > 25) |>
  nrow()
[1] 1653
# men older than 25

People who are either below 68 or female.

sbs399 |>
  filter(age < 68 | sex == 1) |>
  nrow()
[1] 3330

Note that filter() drops rows for which the condition evaluates to NA. In this dataset age and sex are complete, so nothing is lost here, but with incomplete data the counts above would exclude those respondents.

4. Comparing three commands

# select(-sex) removes the COLUMN sex; all rows are kept.
# filter(sex != 1) removes ROWS for which sex equals 1; the column stays.
# filter(sex == 1) keeps only the rows for which sex equals 1.
#
# The two filter() commands look like opposites, but they are not exact
# complements in general: rows with a missing value on sex are dropped by
# both, because NA != 1 and NA == 1 both evaluate to NA rather than TRUE.

Demonstrate this with the number of rows and columns.

dim(sbs399)
[1] 3350   51
dim(select(sbs399, -sex))
[1] 3350   50
dim(filter(sbs399, sex != 1))
[1] 1699   51
dim(filter(sbs399, sex == 1))
[1] 1651   51
# the first command changes the number of columns, the other two the number of rows

How many households with ties?

# Using only filter()
sbs399 |>
  filter(age == max(age), .by = hrespnr) |> # select oldest
  filter(n() > 1, .by = hrespnr) |> # keep rows for households with more than one row

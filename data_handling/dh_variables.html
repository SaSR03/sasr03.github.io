Creating new variables

In this part you will learn about the following basic tasks:

  • Creating a binary (0/1) variable.

  • Recoding a categorical variable.

  • Recoding a continuous variable into groups.

  • Centering and standardizing variables.

  • Reverse coding of variables.

  • Creating additive scales.

R

To create or modify existing variables in a dataset, we will use the function mutate().

The table below shows useful functions for recoding variables. These functions are normally used within mutate().

Function Description
if_else() Create/modify based on simple logical condition
case_when() Create/modify based on multiple logical conditions
recode_values() Recode values (dplyr version >= 1.2)
replace_values() Replace values (dplyr version >= 1.2)
across() Applies function to multiple columns

Examples:

Create a variable as a mathematical expression of existing variables:

data <- data |>
  mutate(
    hhinc = h_inc + w_inc,
    minc = (h_inc + w_inc) / 2,
    adiff = abs(age - page),
    inc2 = inc^2
  )
# sum, mean, absolute difference, and squared income (^ denotes "power")

Change negative values of an existing variable:

data <- data |>
  mutate(
    inc = if_else(inc < 0, 0, inc)
  )
# replace negative of values of inc by 0

Create a binary (“dummy”) variable:

# Create binary variable male. 
# Suppose that sex is coded as female=1, male=2, and there are no missings

# The variable can be numerical (0/1)..
data |>
  mutate(
    male = if_else(sex == 2, 1, 0) # male = 1, female = 0. In thise case, we could also simply do `male = sex - 1`
  )

# or logical (TRUE/FALSE)...
data |>
  mutate(
    male = (sex == 2) # male = TRUE, female = FALSE
  )

For many uses in R, having a binary variable as numeric (1/0) or logical (TRUE/FALSE) makes little difference. For example, R will treat TRUE/FALSE as 1/0 if you compute the mean of a logical vector. Logical binary variables can make code a bit more succint when they are used in other operations: with logical vectors you can write e.g filter(male, employed) instead of filter(male == 1, employed == 1). But be aware that some mathematical and modelling functions expect only numerical variables.

In the code above, we presumed thhat there were no missing values. If there were missing values, they would be coded as 0, which is obviously wrong. To deal with with missing values:

data <- data |>
  mutate(
    male = recode_values(sex,
                         1 ~ 0,
                         2 ~ 1) # Change 1 into 0, 2 into 1
  )
# By default, recode_values() assigns missing (NA) to any values we did not specify. So any NAs would stay as NAs, and any values otehr than 1 and 2 would become NA).

Recode a dummy variable:

data <- data |>
  mutate(
    female = 1 - male
  )
# male = 1 becomes female = 0 and vice versa
# NA values remain NA

Recode values into categories:

# create region variable
# 71, 72, 79 = 1
# 73 to 78 = 2
# all other valide (non NA) codes = 3
data <- data |>
  mutate(
    region = recode_values(country,
                            c(71, 72, 79)  ~ 1,
                            73:78          ~ 2,
                            NA ~ NA,
                            default = 3 # this applies to all other values not speficied above. 
                                        # Attention: if we had nto specified NA ~ NA above, 
                                        # NA values would also have been recoded to 3
    )
  )

You can also recode using case_when(), specifying logical conditions instead of original values on the lef-hand side. case_when() is thus more flexible (e.g. it can handle conditions based on multiple original variables, see below) but tends to more verbose.

# Same task as above, using case_when().
# Note that we explicitly refer to the original variable in each condition
data <- data |>
  mutate(
    region = case_when(
      country %in% c(71, 72, 79) ~ 1,
      country %in% 73:78         ~ 2,
      !is.na(country)            ~ 3,
      is.na(country)             ~ NA
    )
  )


# Recoding based on multiple existing variables
data <- data |>
  mutate(
    group = case_when(
      (male==1 & age < 18)  ~ "male_minor",
      (male==1 & age >= 18) ~ "male_adult"
      (male==0 & age < 18)  ~ "female_minor",
      (male==0 & age >= 18) ~ "female_adult"
      .default              ~ NA  # Everything else as NA. Note the dot in .default.
    )
  )

Create a standardized variable (z-scores):

data <- data |>
  mutate(
    zedu = (edu - mean(edu, na.rm = TRUE)) /
      sd(edu, na.rm = TRUE)
  )
# standardize edu

Create a rank variable:

data <- data |>
  mutate(
    rinc = rank(inc)
  )
# rank order statistics of income

With across() you can repeat operations across several columns:

# Create a new variable counting the number of variables with value == 2:
data <- data |>
  mutate(
    ngood = rowSums(
      across(good01:good05, ~ .x == 2), # for each variable good1 to good5, check if the value is 2
      na.rm = TRUE
    )
  )

# Change 9999 to NA in all variables whose names start with "income" 
data <- data |>
  mutate(
         across(starts_with("income"), ~if_else(.x == 9999, NA, .x))
         )

5. Creating scales

We consider the five items sexrol1 to sexrol5 in the dataset sbs399. These items measure attitudes towards women’s emancipation by (5 point) Likert items. We want to average the 5 items and treat it as a measurement of attitude, with a larger value indicating a more traditional attitude.

  1. Explain why it is not sensible to simply add the five items.

  2. You likely want to reverse one of the items. Which one? Construct a new variable for this reversed item using:

  • a recoding approach with recode_values() (or case_when());
  • a mathematical expression. Verify that both constructed variables are identical.

  1. Create the attitude measure from the five items. Hint: use rowMeans(). What is the mean of the measure? Can you interpret this mean substantively?

  2. The data used so far are complete, meaning that respondents answered all items. In many surveys, however, respondents do not answer every question. This situation is illustrated by the dataset sbs399_sexroles. We will now discuss a simple ad hoc method to deal with this. This method is quick-and-dirty; it used to be widely used, but theoretical statistics has yielded better methods. We will discuss these more advanced methods later on.

For now we simply take the mean of all valid item responses for each respondent. Thus, if a respondent answered items 1, 2, and 3, but not items 4 and 5, we calculate the scale score as the mean of items 1, 2, and 3. If a respondent answered all items, we take the mean across all items. If a respondent did not answer any of the items, the scale score should be missing as well.

In R, this can be accomplished using the argument na.rm = TRUE in rowMeans() (or in mean() used together with rowwise()), which computes the mean using all available values while ignoring missing values.

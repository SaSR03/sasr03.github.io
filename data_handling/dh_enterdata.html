Creating a system file from raw data

In this part you learn about reading raw data into R. Raw data are often stored as text files that can be opened using a simple text editor. Typically the data are in the form of a data matrix in which the rows are cases, columns are variables, and values are separated by commas, tabs, or spaces.

In modern R workflows, raw data are usually read from files such as CSV, tab-delimited text files, Excel files, or Stata files. Occasionally, it is also useful to create a small dataset manually in R, for example for examples, tests, or teaching.

R

In this part you need to learn and read about the following R functions:

Function Description
read_csv() Read comma-separated text data
read_tsv() Read tab-separated text data
read_table() Read whitespace-separated text data
read_dta() Read a Stata dataset
write_csv() Save data as a CSV file
write_rds() Save data as an R object
tribble() Manually create a small dataset
View() Inspect a dataset in RStudio

Examples:

Read a CSV file:

library(readr)
data <- read_csv("data/mydata.csv")

Read a tab-delimited text file:

data <- read_tsv("data/mydata.txt")

Read a whitespace-separated text file:

data <- read_table("data/mydata.dat")

Read a Stata dataset:

library(haven)
data <- read_dta("data/mydata.dta")

Create a small dataset manually:

library(tibble)
data <- tribble(
  ~hrespnr, ~city,        ~female, ~edu,
  101,      "Amsterdam",  1,       3,
  103,      "Den Haag",   0,       5,
  107,      "Rotterdam",  0,       2,
  109,      "Utrecht",    1,       3
)

Inspect the dataset:

View(data)

Save the dataset as a CSV file:

write_csv(data, "data/mydata.csv")

Save the dataset as an R object:

write_rds(data, "data/mydata.rds")

1. Manual entering data

Enter the data by hand with tribble().

mydata <- tribble(
  ~hrespnr, ~city,        ~female, ~edu,
  101,      "Amsterdam",  1,       3,
  103,      "Den Haag",   0,       5,
  107,      "Rotterdam",  0,       2,
  109,      "Utrecht",    1,       3
)

mydata
# A tibble: 4 × 4
  hrespnr city      female   edu
    <dbl> <chr>      <dbl> <dbl>
1     101 Amsterdam      1     3
2     103 Den Haag       0     5
3     107 Rotterdam      0     2
4     109 Utrecht        1     3
# tribble() lays the data out row by row, so the code looks like the table
# the column names are preceded by a tilde

Check what R made of the variable types.

glimpse(mydata)
Rows: 4
Columns: 4
$ hrespnr <dbl> 101, 103, 107, 109
$ city    <chr> "Amsterdam", "Den Haag", "Rotterdam", "Utrecht"
$ female  <dbl> 1, 0, 0, 1

Save this version.

write_rds(mydata, "data/mydata_tribble.rds")
# .rds keeps the object exactly as it is, including variable types

Now build the same dataset as a CSV file. Writing the file from R is the reproducible way to do it; you could equally well type it in a text editor and save it as data/mydata.csv.

csv_text <- "hrespnr,city,female,edu
101,Amsterdam,1,3
103,Den Haag,0,5
107,Rotterdam,0,2
109,Utrecht,1,3
"

write_file(csv_text, "data/mydata.csv")
# the first line holds the variable names, each following line is one case
# values are separated by commas, without spaces after them

Look at the file as plain text, the way a text editor would show it.

A remark on types. read_csv() guesses the type of each column from its contents, whereas tribble() takes the types from what you typed. Here both give the same result, but a guess can go wrong: an identifier with leading zeros, such as a postcode 0234, would be read as the number 234. You can override the guess.

mydata_typed <- read_csv(
  "data/mydata.csv",
  col_types = cols(
    hrespnr = col_character(),
    city = col_character(),
    female = col_double(),
    edu = col_double()
  )
)

glimpse(mydata_typed)
Rows: 4
Columns: 4
$ hrespnr <chr> "101", "103", "107", "109"
$ city    <chr> "Amsterdam", "Den Haag", "Rotterdam", "Utrecht"
$ female  <dbl> 1, 0, 0, 1
$ edu     <dbl> 3, 5, 2, 3
# hrespnr is now text, which is what an identifier really is

Finally, a note on why .rds and .csv are both useful. A CSV file can be opened by any program and read by anyone, but it stores only text and loses the variable types. An .rds file preserves the R object exactly, but only R can read it.

list.files("data", pattern = "^mydata")
[1] "mydata.csv"         "mydata_csv.rds"     "mydata_tribble.rds"

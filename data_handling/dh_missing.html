Dealing with missing data

As one of the more serious of the ten plagues of the social sciences, we now turn to missing values. We will not discuss extensively how to deal with missing values in a statistically appropriate way. Suppose you want to fit a regression model of Y on X1 and X2. What should you do if Y, X1, or X2 are sometimes missing? Some possible approaches:

  • listwise deletion: discard all observations that are missing on one of the variables. This method is also known as “complete observations only”, and is the default approach used by many statistical functions in R.

  • pairwise deletion: correlations and covariances for two variables are computed from all observations that are not missing on those two variables. This method is available in functions such as cor() through the argument use = "pairwise.complete.obs".

  • single imputation methods make the data complete by imputing “reasonable” values for the missing values. The keyword here is of course “reasonable”. A widely used method is the imputation of missing values of x with the mean of x. A somewhat better single imputation method uses predictions from a regression model, or random draws from the forecasted values of a regression model. The hot deck method imputes a missing value in observation i on x by the non-missing value of x in the observation j that most closely resembles observation i.

  • multiple imputation methods impute missing values by multiple values, representing the distribution of plausible values for the missing values, conditional on the observed values and a model for the joint distribution of all variables. Time permitting, multiple imputation methods will be discussed later in the programme. In R, the package mice is commonly used for multiple imputation.

R

In this part you need to learn about the following R functions and packages:

Function Description
na_if() Recode values to missing
replace_na() Recode missing to values
is.na() Test whether values are missing
vis_miss() Description and visualization of missing values

Examples:

Create a dummy variable for whether educ is missing:

data <- data |>
  mutate(educ_mv = is.na(educ))
# educ_mv is a logical dummy (TRUE/FALSE)

Create a dummy male, set to missing if sex is missing:

data <- data |>
  mutate(
    male = if_else(sex == 1, 1, 0)
  )
# assumes sex == 1 is male
# if_else() propagates NA from its condition: when sex is NA, the condition
# sex == 1 is also NA, so male becomes NA automatically.

List edu for observations for which age and country are not missing:

data |>
  filter(!is.na(age), !is.na(country)) |>
  select(edu)

Recode the values 98 and 99 of edu into missing values:

data <- data |>
  mutate(
    edu = na_if(edu, 98),
    edu = na_if(edu, 99)
  )

Recode missing values to 99:

data <- data |>
  mutate(
    edu = replace_na(edu, 99)
  )

Count the number of missing values in a variable:

data$educ |>
  is.na() |>
  sum()

Count the number of missing values per variable in a series of variables:

data |>
  summarise(
    across(starts_with("good"), \(x) sum(is.na(x)))
  )

skimr::skim() gives the same information, together with other descriptive statistics, for any set of selected variables:

library(skimr)

data |>
  select(starts_with("good")) |>
  skim()
# the n_missing and complete_rate columns report missingness per variable

Display missing value patterns and their frequency in a series of variables:

library(visdat)

data |>
  select(good01:good05) |>
  vis_miss()

  mutate(

hin95_educ <- hin95_educ |>
  mutate(

hin95_educ <- hin95_educ |>
  mutate(

# .by = sex makes mean() compute a separate mean within each sex

Model testing

Assignments

sesam

Use the dataset sesam.

  1. Fit a restricted model of postnumb on age and prenumb, and a full model that adds prelet, prerelat, and peabody. Does adding this set of three predictors significantly improve the overall fit? Test this in two ways:
  1. A Wald test using the F-statistic. There are several ways to do this in R: - anova(fit_restricted, fit_full) - car::linearHypothesis(fit_full, c("prelet = 0", "prerelat = 0", "peabody = 0")) - marginaleffects::hypotheses(fit_full, joint = c("prelet", "prerelat", "peabody")) - Any of the three will work, but we recommend the third one because marginaleffects is a super useful package, so it is worth getting acquainted with it.
  2. A likelihood ratio test comparing the two models using lmtest::lrtest().
  1. Test whether the effect of prenumb on postnumb while controlling for age is significantly different for boys and girls. (Hint: it’s an interaction)

donations

Use the dataset donations. As before, treat the “miscellaneous” category of religion as missing. Construct propdon, the proportion of monthly income donated, and percdon, this proportion expressed as a percentage. Use the latter as outcome variable. Construct a dummy variable old for subjects older than 40.

  1. Is there evidence that older people (over 40) donate a larger share of their income than younger people, controlling for religion?

  2. Is there evidence that men donate a larger share of their income than women, controlling for religion?

  3. Using the model from the previous question, test whether religion as a whole contributes to explaining percdon, controlling for gender. Note that this amounts to testing the hypothesis that all religion coefficients are zero.

2

We can of course informally compare the coefficients for prenumb in the two separate models for males and females, but this does not give us a formal test of whether the difference is significant. We should simply fit a model with an interaction between prenumb and sex, controlling for age.

# Creating a numeric female dummy just for cleaner labels in the regression table
# You should get the same results using, e.g., factor(sex)
sesam <- sesam |> 
           mutate(female = as.numeric(sex==2))

fit_male <- lm(postnumb ~ prenumb + age, data = sesam |> filter(sex == 1))
fit_female <- lm(postnumb ~ prenumb + age, data = sesam |> filter(sex == 2))
fit_interaction <- lm(postnumb ~ prenumb * female + age, data = sesam)

modelsummary(list("Boys" = fit_male, "Girls" = fit_female, "Pooled" = fit_interaction), stars = TRUE)

Tip

There is way of combining estimates from separate models and then formally comparing coefficients across models. It is called “seemingly unrelated estimation” (suest) and was originaly developed in a Stata package by a former SaSR03 teacher, Jeroen Weesie. (see here, p. 34). There is a R package, which must be installed from Github, implementing this method. We are skiping suest in the course, but provide the relevant code below for illustration. Nte that it also uses function from the marginaleffects package the we previously loaded.

# The lines below are commented out for technical reasons, but you can run this code in your own R session if you want to try it out. 
# install.packages("remotes")
# remotes::install_github("tdmize/suest")
library(suest)

combined <- suest(fit_male, fit_female, model_names = c("Male", "Female"))
effects <- avg_comparisons(combined, variables = "prenumb")
effects

 Female    0.897     0.0695 12.91   <0.001 124.3 0.761  1.034

Term: prenumb

hypotheses(effects, hypothesis = difference ~ pairwise)

        Hypothesis Estimate Std. Error    z Pr(>|z|)   S   2.5 % 97.5 %
 (Female) - (Male)    0.224      0.136 1.64    0.101 3.3 -0.0438  0.491

Note that the estimate (0.224) is the difference between the coefficients of prenumb estimated separately for females (0.897) and males (.674). The difference is deemed not significant at the 5% level. We conclude the same thing with this method as with the interaction coefficient shown above: the effect of prenumb on postnumb does not significantly differ between boys and girls.

Bonus: Also note that the difference between coefficients estimated with different models (0.224) is not identical to the the interaction coefficient in the pooled model (0.208), even though they are supposed to measure the same thing (“by how much the effect of prenumb differs between males and females”). Change the interaction model above to also include an interaction term between sex and age, and look again at the the sex*prenumb coefficient. What happened? Why?

As in question 1, there are multiple ways of doing this. Here we will do a Wald test using the F-statistic using marginaleffects::hypotheses(). Note that we need to use the coefficient names as they appear in the model summary.

hypotheses(fit_male_don, joint = c("religioncatholic", "religionreformed", "religionrereformed", "religionislam"))


Joint hypothesis test:
religioncatholic = 0
religionreformed = 0
religionrereformed = 0
religionislam = 0

 45.6   <0.001    4  519

The F-statistic is significant, which means that the fit improves between a model without religion and a model with religion. We conclude that religion as a whole does significantly contribute to explaining percdon, controlling for gender.

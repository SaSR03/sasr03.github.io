Multinomial logistic regression

Code tips: - Use multinom() from the nnet package to fit multinomial logistic regression models. - Use relevel() to set the reference category for factor (i.e. categorical) variables. - To correctly display a multinomial model in modelsummary(), you have to specify the shape argument. We suggest the following: shape = term + statistic ~ response. This rearranges the table so that each response category is displayed in a separate column. You might also try other shapes, such as term + response ~ statistic. Whats looks best will depend on the number of response categories, number of predictors in your model, and whether you are displaying more than one model in the same table.

  2. Refit the same empty model using category “social liberal” as the base category instead. How are intercepts now interpreted? What does it mean that the intercept/constant for social democratic is not significant?

  3. Create a dummy variable female. Recode religion into a new variable rel4 with four categories (1: nonreligious; 2: catholic; 3: protestant (reformed, rereformed); 4: other; the rest missing). Fit a multinomial logistic regression for voting (party6) with predictors education (trated as continuous), rel4 (categorical), and female, using category “christian democratic” as the base category for party6.

  1. What is the odds ratio for voting strictly religious rather than Christian democratic for one additional unit of education?
  2. What is the odds-ratio for voting strictly religious rather than Christian democratic for non-religious people versus protestants. Youy might need to change the reference category for rel4.
  1. Using the same model from 4a, compute and interpret the average marginal effects of:
  1. education and female on the probability to vote social democratic.
  2. being catholic versus non-religious on the probability to vote christian democratic.
  1. Recode education into a variable edu4 with four levels (1 to 1; 2 and 3 to 2; 4, 5 and 6 to 3; 7, 8 and 9 to 4; other values to missing). Treat as a categorical variable.
  1. Fit a multinomial model of party6 on edu4 and rel4, using “left” as the base category.
  2. Refit the model adding the interaction between edu4 and rel4. Test whether this interaction significantly improves the fit, using a likelihood ratio test comparing the two models. Is there evidence for an interaction between education and religion on party choice?
  3. We claim that the second model that you just fitted is actually saturated: the predicted probabilities for each combination of categories of edu4 and rel4 exactly matches the observed fractions for these combinations (considering only nonmissing values). Check this by looking at a few combinations of edu4 and rel4: - Predicted probabilities: predict(model_6b, newdata = data.frame(rel4 = "protestant", edu4 = "3"), type="probs") - Observed fractions: hin95_voting |> filter(rel4=="protestant", edu4=="3", !is.na(party6)) |> janitor::tabyl(party6) - You might need to run options(scipen=999) so that small fractions are not displayed in scientific notation.

  1. One unit of education is associated with an odds ratio of 1.079 for voting strictly religious rather than Christian democratic. This means that for each additional unit of education, the odds of voting strictly religious rather than Christian democratic increase by about 7.9%. But the effect is not statistically significant at the 5% level.

  2. We can see from the coefficient rel4protestant that protestants are eight times more likely to vote strictly religious rather than Christian democratic than non-religious people (the reference category for rel4). We can obtain the odds ratio for non-religious people versus protestants by taking the inverse of this odds ratio, which is 1/8.11 = 0.123. But it is better to estimate it precisely by changing the reference category for rel4:

# We can change the ref category directly in the model formula, but could also relevel the variable in the data frame first (which would produce nicer labels).

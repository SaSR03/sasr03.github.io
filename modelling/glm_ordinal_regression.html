Ordinal logistic regression

In this part you will learn about the following basic tasks:

  • Recognize when an outcome variable is ordinal (ordered categories, but with an unknown “distance” between categories), and fit an ordered (proportional odds) logistic regression model.

  • Interpret coefficients as log odds, and transform them into odds ratios.

  • Compute and interpret marginal effects on predicted response probabilities.

  • Obtain predicted probabilities for each response category, and check that they sum to 1.

  • Compare nested ordinal models using a likelihood ratio test, including a check on identical sample sizes.

  • Test whether a predictor’s effect is adequately captured by a linear term, or whether a quadratic term or a fully flexible (categorical) specification fits better.

  • Include an interaction between a quantitative and a categorical predictor in an ordinal model.

  • Compute a pseudo-\(R^2\) for the latent (underlying continuous) variable.

  • Test the proportional odds (parallel lines) assumption.

The ordered logit model

An ordinal outcome variable has categories that can be ranked (e.g., “certainly not voting” < “probably not voting” < “probably voting” < “certainly voting”), but the distances between adjacent categories are not necessarily equal or even meaningful. Treating such a variable as if it were a plain numeric scale in an ordinary regression assumes equal distances between categories, which is often not appropriate. Treating it as unordered (multinomial) categories throws away the ordering information. Ordinal (ordered) logistic regression — also called the proportional odds model — is designed specifically for this situation.

The model assumes there is an unobserved (latent) continuous variable \(Y^*\) underlying the observed ordinal outcome:

\[ Y^* = b_1 X_1 + \dots + b_k X_k + \varepsilon \]

The observed category is determined by where \(Y^*\) falls relative to a set of unknown thresholds (cutpoints). The coefficients \(b_j\) describe the effect of each predictor on this latent variable, and — under the proportional odds assumption — this same coefficient applies uniformly to every cutpoint between adjacent response categories.

Interpreting coefficients

As with binary and multinomial logistic regression, there are several common ways to interpret an ordinal logistic regression coefficient:

  1. Log odds (on the latent scale). A one-unit increase in \(X_j\) is associated with a \(b_j\) increase in the latent variable underlying the outcome, holding other predictors constant. Equivalently, it changes the log odds of being in a higher response category (versus any set of lower categories) by \(b_j\), uniformly across all cutpoints.

  2. Odds ratios. Exponentiating the coefficient, \(\exp(b_j)\), gives the change in the odds of being in a higher rather than a lower response category, for a one-unit increase in \(X_j\). This interpretation, like the binary logistic case, applies uniformly across cutpoints under the proportional odds assumption.

  3. Marginal effects on response probabilities. These translate the model to the probability scale, giving the average change in the predicted probability of each individual response category for a one-unit change in a predictor. Because there are several ordered categories, the marginal effect is typically negative for some categories and positive for others — a predictor that increases the latent variable will, on average, shift probability mass away from the lower categories and toward the higher ones.

Comparing nested models

As in previous chapters, a set of predictors can be tested jointly using a likelihood ratio (LR) test comparing a restricted and a full model. A common pitfall is that the two models being compared must be fit to exactly the same set of observations. If one of the predictors in the full model has missing values that the restricted model’s predictors do not, the two models are fit to different samples, and the LR test between them is not valid. Always re-fit the restricted model on the same (listwise-deleted) subsample as the full model before comparing.

Checking the functional form of a predictor

A quantitative predictor is often entered linearly, assuming its effect on the latent variable is a straight line. This assumption can be checked by comparing the linear specification to a model where the predictor is entered as a set of dummies (fully flexible, one parameter per category) or with a quadratic term added. If neither alternative fits significantly better than the linear specification, the linear form is an adequate simplification.

A pseudo-\(R^2\) for the latent variable

Because the ordinal logit model has a latent continuous variable underneath it, a natural (although not the only) \(R^2\)-type measure is:

\[ R^2 = \frac{\text{Var}(\widehat{Y^*})}{\text{Var}(\widehat{Y^*}) + \text{Var}(\varepsilon)} \]

where \(\widehat{Y^*}\) is the fitted linear predictor (the model without the error term), and \(\text{Var}(\varepsilon) = \pi^2/3 \approx 3.29\) is fixed by the logistic distribution used for the error term in the ordered logit model.

The proportional odds assumption

The key assumption of the ordered logit model is that the effect of each predictor is the same across all cutpoints (the “proportional odds” or “parallel lines” assumption). This can be tested formally (e.g., with a Brant test). If the assumption is violated, a model that allows the effect to differ across cutpoints (such as a generalized ordered logit or partial proportional odds model) may be more appropriate; such extensions are beyond the scope of this course, but it remains important to check the assumption and report when it does not hold.

You will learn the R functions listed below to fit and interpret ordinal logistic regression models.

Function Description

summary() Display coefficients (log odds) and cutpoints

lmtest::lrtest() Likelihood ratio test comparing two nested ordinal models

Examples:

Construct the predictors and fit an ordered logit model:

library(tidyverse)
library(haven)
library(MASS)

data <- read_dta("data/hin95_voting.dta")

data <- data |>
  mutate(
    age = 95 - birthdate %% 100,
    female = as.integer(sex == 2),
    chfreq = case_match(
      church,
      1 ~ 0, 2 ~ 1, 3 ~ 12, 4 ~ 52,
      .default = NA_real_
    ),
    vote = factor(vote, ordered = TRUE)
  )

fit <- polr(vote ~ education + age + female + chfreq, data = data, Hess = TRUE)
summary(fit)

MASS::polr() reports coefficients as log odds by default. Always verify the direction of an effect against the observed data (for instance with a cross-tabulation of the outcome against a predictor), since the sign convention for the latent variable and its cutpoints differs between implementations.

Obtain odds ratios and their confidence intervals:

exp(coef(fit))
exp(confint(fit))

Average marginal effects on the probability of each response category:

library(marginaleffects)

avg_slopes(fit)

Predicted probabilities for each response category, for every observation:

data <- data |>
  mutate(pr = predict(fit, type = "probs"))

data |>
  filter(irespnr == 1000) |>
  pull(pr)

# check that probabilities sum to 1 (within rounding) for a subject
rowSums(predict(fit, type = "probs"))

Test a hypothesis on one predictor with a likelihood ratio test, making sure both models use the same (listwise-deleted) sample:

fit_a <- polr(vote ~ education + age + female + chfreq, data = data, Hess = TRUE)

data_complete <- data |> filter(!is.na(chfreq))

fit_b <- polr(vote ~ education + age + female, data = data_complete, Hess = TRUE)
fit_a_same_sample <- polr(vote ~ education + age + female + chfreq, data = data_complete, Hess = TRUE)

lrtest(fit_a_same_sample, fit_b)

Check the linearity of a predictor: compare a linear specification, a fully flexible (factor) specification, and a quadratic specification:

fit_linear <- polr(vote ~ education + age + female + chfreq, data = data_complete, Hess = TRUE)
fit_flexible <- polr(vote ~ education + age + female + factor(chfreq), data = data_complete, Hess = TRUE)
fit_quadratic <- polr(vote ~ education + age + female + chfreq + I(chfreq^2), data = data_complete, Hess = TRUE)

lrtest(fit_linear, fit_flexible)
lrtest(fit_linear, fit_quadratic)

Include an interaction between a quantitative and a categorical predictor:

fit_interaction <- polr(vote ~ education + age + female * chfreq, data = data_complete, Hess = TRUE)
fit_no_interaction <- polr(vote ~ education + age + female + chfreq, data = data_complete, Hess = TRUE)

lrtest(fit_interaction, fit_no_interaction)

Compute a pseudo-\(R^2\) for the latent variable:

fit_r2 <- polr(vote ~ education + age + female + chfreq, data = data_complete, Hess = TRUE)

lp <- predict(fit_r2, type = "linear.predictor")
# not all versions of polr expose this directly; the linear predictor
# can also be computed manually as X %*% coef(fit_r2)

var_lp <- var(lp)
r2 <- var_lp / (var_lp + pi^2 / 3)
r2

Test the proportional odds assumption:

library(brant)

brant(fit_r2)
